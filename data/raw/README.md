# Raw Evidence

This directory holds original, unmodified security evidence files used for ingestion and testing.

**Files in this directory must never be modified after creation.**

Acceptable formats (future):
- Syslog / journald exports (.log)
- Windows Event Log exports (.evtx, .json)
- Zeek/Suricata logs (.json, .log)
- EDR telemetry exports (.json, .csv)
- PCAP metadata exports (.json)
